# Web Calculator 🔢

**Web Calculator** is a simple and fully functional calculator built using **HTML**, **CSS**, and **JavaScript**. It allows users to perform basic arithmetic operations like addition, subtraction, multiplication, and division. The calculator features a clean, responsive design and interactive buttons that update the display in real-time, providing a smooth and intuitive user experience. It's a beginner-friendly project ideal for learning and practicing front-end web development.

## 💻 Technologies Used

- HTML5  
- CSS3  
- JavaScript (ES6)
